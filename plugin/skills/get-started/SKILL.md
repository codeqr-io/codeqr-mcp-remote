# Get started with CodeQR

Run this once, right after the plugin is installed. Keep every message short and in plain language. Reply in the language the person writes in.

1. Greet them in one sentence and ask what they want to make first. Offer these four examples:
   - a menu code for a restaurant, for tables or packaging
   - a code on a flyer or poster that opens a booking page for a local service
   - a shop Wi-Fi code, or a code for a product or a shelf
   - a code printed on packaging or a sign

2. Collect what the code needs:
   - If the code opens a page, ask for the real link. Never invent a link and never use a placeholder such as example.com.
   - If it is a Wi-Fi code, ask for the network name, the password and the security type (WPA2, WPA, WEP or open).

3. Create the code with the CodeQR tools and show the result.

4. Close in one or two sentences: the page the code opens can be changed later without reprinting it, and they can ask at any time how many times it was scanned.
